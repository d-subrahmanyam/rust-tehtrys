# Appendix B — Tetrimino Data

The seven tetriminos; colors; explicit per-orientation cells; spawn. §1.4/§3 +
A1.3. **Local coordinates are 0-based, y-down, relative to the bounding-box
top-left.** Global = `origin + local`. Orientation tables are explicit (no runtime
rotation math); kicks in [appendix A](A-srs-kick-tables.md).

> **Honesty.** These match the published **Super Rotation System** orientations
> (guideline A1.3). Cannot machine-read PDF diagram pixels; **conformance tested**
> (rotation composition returns to start; kicks invert; spawn matches §3.4).

## O spawn (§3.4, §5.2 resolved)

O is a **2×2** (§1.4). **Guideline §5.2 gives exact spawn cells: O occupies columns
5–6, rows 21–22** `(5,21)(6,21)(5,22)(6,22)`, centered; piece's center (Rotation
Point 1) at `(5,21)`; then **drop-1-row-if-clear** (§3.4/§5.3). Converted to engine
(y-down, 0-based): **origin (4,18)**, occupied **(4,18)(5,18)(4,19)(5,19)**;
horizontally centered **cols 4–5**. (Note: guideline's §3.4 "O on 5th/6th cell
row-21" + §5.2 "rows 21–22" + a local-only text conversion confirm; earlier
honest flag resolved.) 

*Box note:* guideline §3.2 renders O in a 3-wide box `.##/.##`; standard SRS uses a
2×2 box. Since **O never kicks & never changes shape**, the produced **cells are
identical**; we use 2×2. Behavior verified by test.

See the 2009 Tetris Design Guideline §3.2/§5.2/§15.4 (source local-only, not distributed).
